🎅 Secret Santa

Aplicação web para realizar sorteios de amigo secreto de forma simples e intuitiva.

🚀 Stack Utilizada
  - Frontend
  - React
  - Vite
  - JavaScript
  - CSS
Backend as a Service (BaaS)
  - Supabase
  - Hospedagem
  - Vercel
✨ Funcionalidades
  - Cadastro de participantes
  - Persistência dos dados
  - Sorteio aleatório
  - Interface responsiva
  - Validação de entradas
🛠️ Como executar
  - git clone https://github.com/Iukkas/Secret-Santa.git
  - cd Secret-Santa
  - npm install
  - npm run dev
